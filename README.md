# My Story Matters Attendance & Engagement Tracker Mockup

This is a lightweight static mockup for a facilitator attendance and engagement tracking application.

## What it does

- Create courses
- Add facilitator information
- Add schedule dates
- Add attendees
- Track attendance for each attendee
- Select engagement level for each attendee
- Capture submission timestamp
- Show a basic leadership dashboard
- Preview overdue/missing attendance items
- Store demo data locally in the browser using `localStorage`

## What it does not do yet

- No login/authentication
- No backend database
- No Monday.com API integration
- No real email notifications
- No real user permissions

## How to host on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js`.
3. Go to repository **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root` folder.
7. Save.
8. GitHub will provide a public URL after deployment.

## Suggested demo flow

1. Click **Load Demo Data**.
2. Select a course.
3. Choose a session date.
4. Change attendance and engagement dropdowns.
5. Click **Submit Attendance**.
6. Review the leadership dashboard mockup.
